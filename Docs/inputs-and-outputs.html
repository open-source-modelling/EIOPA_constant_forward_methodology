EIOPA risk-free rate in Python

Inputs, calculation and outputs

The code reads up to four CSV files, calculates the Solvency II basic risk-free interest rate term structure with EIOPA's constant-forward method, optionally adds the volatility adjustment and the interest rate shocks, and writes up to six CSV files. EIOPA's Excel workbook calculates the same results; this page shows the cell for each one.

At a glance

A run has up to three steps. The first always runs; each of the other two runs only when its input file is there.

Run the scripts

python Code/main.py

Reads Input/ and writes Output/, which is deleted at the start of every run so it only holds the latest results.

Run the package

eiopa-rfr --input Input --output Output

The same calculation after pip install eiopa-rfr. It deletes only result files of an earlier run from the output folder, so other files there are kept.

Both print a summary (FSP, LLFR, VA and the curves at selected maturities) and the path of every file written.

The VA takes two runs

  1. Fill in the spreads and settings and leave the four amounts empty. The run writes the CSSR curve (<prefix>_va_curves.csv, column CSSR Curve) and reports CSSR : not calculated.
  2. Value your fixed income assets and best estimate on the basic risk-free rate and on the CSSR curve, enter the four amounts and run again. The run now calculates the CSSR, the VA and the curve with VA.

Checks before anything is calculated

Each file is checked in full and every problem is listed at once, for example Input error: invalid inputs: - UFR must be a decimal, e.g. 0.033 for 3.3% (is 3.3).

parameters.csv and curve.csv

  • Instrument is SWP or GVT; swaps have a Coupon Frequency of at least 1.
  • Convergence is positive; UFR and every rate lie between −1 and 1.
  • No DLT flag, weight or rate lies beyond Max Maturity.
  • At least one maturity has DLT 1 and a rate.
  • LLFR weights are not negative, sum to 1, and sit only on DLT maturities with a rate.
  • A DLT maturity with a rate comes before the FSP.

va_parameters.csv

  • The spreads lie between −1 and 1.
  • The four amounts are given all together or not at all.
  • With the amounts, the notional VA is not 0.
  • The macro VA has the country RCS and a debt-to-total-assets ratio between 0 and 1.
  • The USA is at most 1.05 and is not combined with the macro VA.

irr_parameters.csv

  • Every maturity up to Max Maturity has all five values.
  • Relative shocks lie between 0 and 1, absolute shocks between 0 and 1 (1 excluded).
  • The floor lies between −1 and 1.

Invalid curve inputs stop the run before anything is written. Invalid VA inputs stop it after the basic risk-free rate is saved; invalid shock parameters after the VA is saved.

What the code does

The calculation follows EIOPA's RFR Technical Documentation (EIOPA-BoS-26/198, May 2026) and is a line-by-line port of the workbook's VBA and worksheet formulas. t is a maturity in years, the superscript c marks a continuously compounded rate, tF is the FSP.

  1. Read and check the inputs

    Every file is read and checked before anything is calculated (see Checks).

  2. Bootstrap the zero curve §8.5.2, Annex D

    Swaps. Each DLT swap is priced at par with its rate reduced by the CRA. Between DLT maturities the periodic forward rate is constant, and each new forward is solved with Newton–Raphson:

    (st − CRA) / m · Σj=1…m·t dj/m + dt = 1

    Government bonds. The rates are already zero rates. After the CRA they are converted to continuous compounding and the forward rate is constant between DLT maturities:

    zct = ln(1 + rt − CRA)

    The result is a zero rate for every year up to the last DLT maturity.

    In Excel: Input Data & Extrapolation K25:K174 R.BOOTSTRAPPED_CURVE (VBA BootstrapCurve)

  3. Calculate the last liquid forward rate §8.3, §8.5.6

    A weighted average of the forward rate into the FSP and the forward rates from the FSP to each later DLT maturity:

    LLFRc = wF · fc(tF − 1, tF) + Σk>F wk · fc(tF, tk)

    In Excel: Input Data & Extrapolation L22 V.LLFR (VBA GetLLFR); the FSP in Input Data & Extrapolation H13 V.FSP

  4. Extrapolate to the UFR §8.5.5–§8.5.8

    After the FSP the forward rate starts at the LLFR and converges to the UFR; a larger α converges faster:

    fc(tF, tF + h) = ln(1 + UFR) + (LLFRc − ln(1 + UFR)) · (1 − e−αh) / (αh)

    Up to the FSP the curve is the bootstrapped curve. The zero rates are converted to annual compounding and rounded to 5 decimals: this is the basic risk-free rate.

    In Excel: Input Data & Extrapolation L25:L174 R.BASIC_RFR (VBA Extrapolation)

  5. Volatility adjustment §9.3, §9.4, §10 with va_parameters.csv

    The CSSR curve is the basic risk-free rate with a notional VA of 85% of the currency RCS (rounded to whole basis points) added to its one-year forwards. Your two valuations on it give the credit spread sensitivity ratio:

    PVBPFI = (FIMV − FICSSR) / notional VA,   PVBPBEL = (BELMV − BELCSSR) / notional VA
    CSSR = max(min(PVBPFI / PVBPBEL, 1), 0), and 1 if PVBPBEL ≤ 0

    The currency VA is 85% · CSSR · RCScu, times the USA if given. With the macro VA, euro area undertakings add 85% · CSSR · max(RCSco − 1.3 · RCScu, 0) · ωco. The total VA is rounded to whole basis points and added to the one-year forwards; the LLFR rises by wF · ln(1 + VA).

    In Excel: sheets CSSR Calculation and VA Term Structures

  6. Interest rate shocks workbook sheets with irr_parameters.csv

    The bootstrapped zero rates after the CRA, annually compounded, are shocked for every maturity up to the last DLT maturity:

    rupt = rt · (1 + supt) + bupt,   rdownt = rt · (1 − sdownt) − bdownt

    Each shocked curve gets its own LLFR and is extrapolated as in step 4 with the UFR shifted by 15 basis points (UFR + 0.15% up, UFR − 0.15% down), then rounded to 5 decimals. The downward curve is raised to the floor of each maturity. With a total VA from step 5, both are also calculated with that VA.

    In Excel: sheets IRR Up Shock and IRR Down Shock

Find the results in Excel

Every output is also calculated by EIOPA's demonstration workbook, kept in the repository as Sources/RFR extrapolation and VA calculation (19 May 2026).xlsm. With the same inputs the two agree exactly: this was checked for every value above, at all 150 maturities.

Open the workbook

Enable macros: the curves come from the VBA functions BootstrapCurve, GetLLFR and Extrapolation, and show #NAME? without them. The sheets use LET, FILTER, XMATCH, BYROW, LAMBDA and HSTACK, so they need Excel for Microsoft 365 or Excel 2024.

Give it the same inputs

Enter the values of your input files in the cells listed under Inputs, and keep Extrapolation? in H10 at TRUE. The workbook in the repository is saved with the inputs of Input/, so Output/ matches it as it opens.

Jump with the Name Box

Most results have a workbook name. Type it in the Name Box, left of the formula bar, and press Enter: V.LLFR selects L22 on Input Data & Extrapolation, R.BASIC_RFR the whole basic risk-free rate.
